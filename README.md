# Kolpo Films

Website for **Kolpo Films**, an AI film and ad studio. Live at https://kolpofilms.github.io

Static site, no build step:

- `content.js`: all text (English + Bangla), work items, services, process, contact details
- `index.html`, `styles.css`, `main.js`: layout, styling and behaviour
- `assets/`: thumbnails, making-of frames and web-sized videos

To update: edit `content.js`, commit, push. GitHub Pages updates in about a minute.
